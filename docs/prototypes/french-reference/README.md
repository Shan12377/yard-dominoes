# French one-screen table reference

Open `index.html` directly or serve the repository and visit this folder.

The **Late hand · 25 played** fixture is the acceptance state. It deliberately
uses uneven arms and multiple doubles so the board cannot pass by looking good
only at the opening pose.

The Opening and Late hand buttons represent two moments in the same hand. The
domino measurement is calculated from the late-hand envelope at startup and is
then locked; switching states must never change it.

Nothing in this folder is production code. The purpose is to settle the table
geometry in isolation, then port the verified measurements to Practice and
Lounge together.
